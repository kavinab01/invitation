# Kavin weds Sivakami — Wedding Invitation

A responsive Next.js wedding invitation website with a traditional South Indian temple-inspired design, animated details, live countdown, event schedule and Google Maps link.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a GitHub repository and upload the contents of this folder.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the framework preset as **Next.js** and deploy. No environment variables are required.

## Customize

- Event names, date/time, address and map link: `app/page.tsx`
- Colors, typography, layout and animation: `app/globals.css`
- Page title and description: `app/layout.tsx`

The countdown targets 22 November 2026 at 10:30 AM India Standard Time.
